# Agenda de Estudos

App web simples para o aluno cadastrar trabalhos, provas e listas por matéria, com data de entrega, e marcar o que já concluiu.

Projeto da atividade de Gerência de Configuração de Software (GCS) — UNASP.

## Como abrir

Não precisa instalar nada: abra `src/index.html` no navegador.

## Como contribuir

Leia `docs/plano-de-configuracao.md`. Resumo:

- nunca altere a `main` diretamente; crie uma branch `tipo/RFxx-descricao`;
- mensagens de commit no padrão `tipo(escopo): descrição` (Conventional Commits);
- o merge só acontece por pull request aprovado por outra pessoa.
